# 🏫 Coaching Website – CLI Institute

This is a static website project created for a coaching center named **CLI**. It features a clean layout, informative sections, and a simple UI made entirely with **HTML and CSS (float-based layout)** — no JavaScript or frameworks.

🔗 **Live Site:** [ronax23.github.io/cli](https://ronax23.github.io/cli/)

---

## 🧩 Project Purpose

This website was built as part of a frontend practice project and showcases:
- Use of float-based CSS layout
- Static HTML structuring
- Real-world use-case simulation (educational institute)

---

## 📌 Features

- Header with logo and navigation bar
- Hero banner section with callout text
- "Why Choose Us" section
- Courses overview
- Features list (notes, tests, interview prep)
- Clean footer with contact and policy links

---

## 🛠️ Built With

- **HTML5**
- **CSS3** using traditional **`float` layout**
- No JavaScript or libraries
